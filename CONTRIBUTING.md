# Contributing

1. Open an issue before changing power-management or authorization behavior.
2. Keep the extension manual-only: do not add schedules, automatic activation,
   battery policies, password storage, privileged helpers, or sudoers rules.
3. Run `npm test`, `npm run lint`, and `npm run build` from
   `raycast-extension/`.
4. State which macOS version and Mac model were tested. Do not claim closed-lid
   reliability without a representative physical test.
5. Do not submit generated binaries, dependencies, personal caches, or secrets.
