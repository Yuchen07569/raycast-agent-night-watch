跟着问卷一步一步完成测试

建议用手机打开飞书问卷，在 Windows 电脑上操作。问卷无需登录，会逐步提示需要记录的信息；中途停止也可以提交已经完成的部分。

打开飞书分步测试问卷

答案保存在项目所有者的飞书表格中。请勿填写姓名、手机号、密码、设备序列号、私人路径或完整日志。

先保证安全。笔记本必须接电并放在硬质、平整、通风的桌面上。不要放进包里，不要遮挡散热，不要关闭 SmartScreen、Defender、Smart App Control 或公司的安全策略。若校验失败、机身明显异常发热、出现警告状态或原设置无法恢复，请立即停止。

1. 下载并校验

从本页下载 ZIP 和 SHA-256 文件。两份文件放在同一个文件夹，在 PowerShell 中运行：

Get-FileHash .\AgentNightWatch-0.2.0-beta.1-windows-x64.zip -Algorithm SHA256

结果必须是：

77B3DB86619D507E897C0FCFC5AEFC7B048EDCEE540D0F7ABF9EF763892BA58A
下载 Windows x64 ZIP 下载校验文件

校验不一致就停止，不要解压或运行。若 Windows 只提示“未知发布者”，先记录提示；仅在校验一致且你愿意继续时运行，不要关闭系统保护。

2. 记录原来的电源设置

打开 Windows 电源设置，记下接电自动睡眠时间。笔记本还要记下接电状态下的合盖动作。这里只记录，不要手动修改。

3. 检查咖啡杯开关

解压 ZIP 并运行 AgentNightWatch.exe。它没有主窗口；若没看到咖啡杯，请点任务栏右侧的 ^。无水汽表示关闭，有水汽表示运行。左键开启，状态稳定后再左键关闭一次。

4. 开始写入心跳

只有准备测试合盖或锁屏熄屏时才需要心跳。在普通 PowerShell 窗口运行下面这一整行并保持窗口打开。结束时按 Ctrl+C。

$p="$env:USERPROFILE\Desktop\agent-night-watch-heartbeat.log"; while($true){$t=Get-Date -Format o; $t | Tee-Object -FilePath $p -Append; Start-Sleep -Seconds 5}

5. 可选：笔记本接电合盖 5 分钟

笔记本保持接电，开启守夜并确认咖啡杯有水汽。合盖 5 分钟，再开盖检查心跳日志。相邻时间通常约 5 秒，没有超过 15 秒的空档可在问卷中选择通过。若机身明显异常发热，请立即开盖并关闭守夜。台式机或不方便合盖的测试者跳过这一步。

6. 可选：检查锁屏熄屏

接电运行时，右键咖啡杯选择 Lock and Turn Off Displays，等待 5 分钟后唤醒显示器。Windows 应要求密码或 Windows Hello，心跳不应出现超过 15 秒的空档。

7. 可选：开盖观察拔电暂停

这一步只给笔记本，并且全程保持开盖。接电开启后拔掉充电器，只观察咖啡杯是否进入暂停状态；重新接电后，水汽应恢复。不需要等待电脑睡眠，也不要修改电池设置。无法安全完成就选择“未执行”。

8. 关闭并逐项确认恢复

左键咖啡杯关闭守夜，再右键选择 Exit。逐项对比测试前记录的接电睡眠时间和接电合盖动作。任何一项不一致都算失败，此时不要直接删除程序，请在问卷里记录并联系邀请人。

完成恢复检查后，再提交测试问卷。

English summary

Open the anonymous Feishu form, verify the ZIP checksum, record the original power settings, test the tray toggle, start the heartbeat if needed, complete the applicable five-minute lid-close or lock-and-display-off test, then disable the utility and verify every original power value has been restored. Keep laptops connected to AC power on a hard, ventilated surface. Stop immediately if verification fails, the laptop becomes unusually hot, a warning appears, or settings cannot be restored.
