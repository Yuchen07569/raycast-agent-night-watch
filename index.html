故事

它是怎么来的

有天晚上十一点，我把一份要跑很久的任务丢给 Codex，准备睡觉。合上 MacBook， 屏幕一黑，任务就断了。开着屏幕，又晃得睡不着。一个两难，卡了我一整晚。

它那么累了，就让它也喝点咖啡吧。于是一个咖啡杯，成了我的守夜人。
功能

只有一个咖啡杯

冒水汽 = 合盖继续跑；没水汽 = 正常睡眠。点一下开，点一下关。

一目了然

水汽即状态

咖啡杯冒着水汽，说明 Agent 有夜班守；水汽消失，电脑照常睡得安安静静。

一次点击

单击切换

正常状态下单击咖啡杯直接开关，不必进菜单，不必敲命令。

严格边界

不碰密码

不存密码、不配免密 sudo、不装常驻特权助手。每次开启都亲自授权。

真实状态

读系统事实

用 macOS SleepDisabled 作为事实源，而不是普通空闲睡眠的断言。

随时可退

可恢复关闭

点一下关掉，电脑立刻恢复正常合盖睡眠。随时给你自由。

与众不同

不是 caffeinate

普通工具防空闲睡眠，它显式控制全局合盖睡眠覆盖，针对合盖场景更准。

FAQ

常见疑问

会一直耗电吗？
只在开启时保持合盖运行。任务跑完点一下关掉，就恢复正常合盖睡眠，不影响续航。
需要会写代码吗？
不用。装上 Raycast 扩展就能用，菜单栏点咖啡杯开关即可。
它对所有 Agent 都有效吗？
它控制的是 macOS 合盖睡眠本身，不只是某个 Agent。只要进程不被合盖睡眠打断，就能持续运行。
为什么不直接用 caffeinate？
caffeinate 通常防空闲睡眠，管不到 MacBook 合盖的睡眠逻辑。它显式控制 SleepDisabled，针对合盖场景更准。
它安全吗？会碰我的密码吗？
不做任何密码/凭据存储。开启触发 macOS 自带管理员授权，不配免密 sudo，不装特权助手。MIT 开源可审计。
会损坏电脑吗？
不会。它只切换一个系统睡眠开关。建议合盖运行时放通风处避免过热。
能和其他工具共用吗？
可以。它只控制合盖睡眠覆盖，不与 IDEs、终端、其他 Raycast 扩展冲突。
